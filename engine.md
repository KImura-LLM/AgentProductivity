# Локальные правила workflow

- После завершения изменений автоматически выполнять commit, push в GitHub и деплой на production-сервер, чтобы изменения можно было сразу проверять вживую.
- Перед commit сохранять базовые проверки проекта: `pytest`, `ruff check .`, `agent-productivity-cli doctor`.
- Не коммитить секреты, `.env`, локальное состояние `.state/` и токены.
